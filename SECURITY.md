# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| main    | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability in Wavelength, please do **not** open a public GitHub issue. Public disclosure before a fix is available puts all users at risk.

Instead, please report it privately:

1. **GitHub private vulnerability reporting** (preferred): [Report a vulnerability](https://github.com/krishsah01/wavelength/security/advisories/new)
2. **Email**: reach the maintainer directly via the contact in the GitHub profile.

### What to include

- A clear description of the vulnerability and its potential impact
- Steps to reproduce (a minimal proof of concept is very helpful)
- The version or commit SHA where you observed the issue
- Any suggested mitigations you are aware of

### What to expect

- Acknowledgement within **48 hours**
- A status update within **7 days**
- A patch and coordinated disclosure timeline once the fix is ready

We appreciate responsible disclosure and will credit reporters in the release notes (unless anonymity is requested).
